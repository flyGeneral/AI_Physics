# 黑洞模拟 · Black Hole Simulator

一个零依赖的黑洞可视化应用：单个 HTML 文件 + WebGL 片元着色器，在浏览器里实时渲染一个
**克尔（Kerr）旋转黑洞**和它的吸积盘。自旋拉到 0 时退化为史瓦西黑洞的快速路径。

## 启动

```bash
cd blackhole
./start.sh            # 直接用默认浏览器打开
./start.sh --serve    # 或者：启动本地服务器 http://localhost:8622
```

也可以直接双击 `index.html` 用浏览器打开。推荐 Chrome / Edge / Safari 等现代浏览器。

## 交互

| 操作 | 效果 |
|---|---|
| 鼠标拖动 | 环绕黑洞旋转视角（含俯仰） |
| 滚轮 / 双指捏合 | 拉近、拉远 |
| 空格 / 暂停按钮 | 冻结吸积盘时间流 |
| 截图按钮 | 保存当前画面为 PNG |

面板里可以调：画质（步数与分辨率）、曝光、吸积盘亮度、时间流速、**自旋 a/M**，
并可开关**引力透镜**（对比时空弯曲前后的画面差异）和**多普勒 + 引力红移**。

## 玩法建议

- **自旋 a/M 从 0 拉到 0.9+**：吸积盘内缘从 6M 一路收缩到约 1.24M（ISCO 随自旋内移），
  黑洞阴影变成不对称的 **D 形**——扁平侧与多普勒增亮的明亮侧同侧，这是参考系拖曳的
  标志性效应。贴着盘面看（俯仰角小）最明显。
- **关掉"引力透镜"**：画面变成无弯曲的平面盘 + 几何球剪影，直观展示时空弯曲的作用。
- **关掉"多普勒"**：盘变回对称亮度，对比出相对论增亮的强度。

## 背后的物理

渲染不做"贴图造假"，而是对每个像素从相机反向发射光线，在弯曲时空中数值积分：

- **克尔时空光线追踪**：采用 Kerr-Schild 形式 `g = η + S k⊗k` 的笛卡尔坐标哈密顿
  公式 `H = ½(p² − p_t²) − ½S(p_t − k·p)²`，RK4 积分 + 每步解二次方程把动量重整化回
  零测地线约束 H=0（守恒到机器精度）。自旋参数 a/M ∈ [0, 0.998] 连续可调。
  积分器经过独立数值验证：梯度与有限差分一致（<1e-8）、a=0 时临界撞击参数
  b=√27·M、a=0.9 时顺/逆行光子轨道半径与解析解吻合到四位小数。
- **史瓦西快速路径**（a≈0）：Binet 形式 `a = -3/2 · h² · r̂ / r⁴`，与克尔路径在
  a→0 处无缝衔接。黑洞"影子"角半径对应临界撞击参数 b ≈ √27/2 · rs ≈ 2.6 rs，
  光子球 r = 1.5 rs 附近的光线绕行多圈，自动形成光子环。
- **吸积盘**：内边缘取在最内稳定圆轨道 ISCO——史瓦西 6M，克尔顺行盘按 Bardeen
  公式随自旋内移（a=0.9 时 2.32M，a=0.998 时 1.24M）。温度按 T ∝ r^(-3/4) 薄盘廓线
  分布，用黑体辐射色映射；纹理随开普勒角速度差速旋转，被自然剪切成螺旋流苏。
- **相对论多普勒 + 引力红移**：盘物质轨道速度 β ≈ √(M/r) 量级，观测温度
  T_obs = T · δ · √(1 − 2M/r)，强度按 I ∝ δ³ 增亮——接近我们的一侧明显更蓝更亮，
  远离的一侧暗红。克尔模式下参考系拖曳使这种不对称更强。
- **背景星空**：纯程序化生成（哈希 + 分形噪声），被引力透镜弯曲后自动出现
  星星拖影和爱因斯坦环。

## 性能

- 史瓦西路径：桌面 GPU 上通常 120 FPS（1080p 级别）。
- 克尔路径：RK4 哈密顿积分每步成本高数倍，应用会自动把渲染分辨率降一档
  （右上角可见实际渲染尺寸），典型 40–80 FPS。觉得慢可以选"流畅"画质。
