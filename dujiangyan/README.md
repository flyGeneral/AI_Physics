# 都江堰分水模型 · Dujiangyan Water Division

一个零依赖的交互式水利工程可视化：单个 HTML 文件 + WebGL，用两万多颗发光粒子
实时演示都江堰"鱼嘴分水、飞沙堰排沙、宝瓶口限流"的运行机理。

## 启动

```bash
cd dujiangyan
./start.sh            # 直接用默认浏览器打开
./start.sh --serve    # 或者：启动本地服务器 http://localhost:8623
```

也可以直接双击 `index.html`。

## 怎么看

场景为俯瞰视角：北侧是岷江上游山区，江水向南流，在**鱼嘴**分水堤处分成
**内江**（东，流向宝瓶口）与**外江**（西，岷江正流），内江途经**飞沙堰**
（溢流堰），末端经**宝瓶口**进入成都平原灌区。

| 操作 | 效果 |
|---|---|
| 拖动 / 滚轮 | 旋转、缩放视角 |
| 上游来水滑块 | 300–5000 m³/s，从枯水期拉到特大洪水 |
| 浑水着色 | 底层含沙粒子显示为琥珀色，看清水沙分道 |
| 环流剖面 | 鱼嘴上游的断面视图 + 右下角横断面插图，演示分沙原理 |

## 清水是怎么"分"出来的

都江堰不设任何滤沙装置，靠三道机关接力（应用内开"环流剖面"可对照）：

1. **弯道环流（鱼嘴选址）**：水流进弯道发育螺旋环流——表层清水惯性大冲向凹岸
  （内江侧），底层挟沙水被河床摩擦拖住沿床面走向凸岸（外江侧）。鱼嘴放在弯道
   顶点、内江开在凹岸正面迎流，粗沙因此跟着底层水进外江（二八分沙）；
2. **飞沙堰二次排沙**：内江弯道环流继续把底沙推向堰侧，洪水期堰头强螺旋涡把
   进入内江的底沙掀起抛回外江（"飞沙"之名由来），宝瓶口侧向取水角度让洪水
   主流裹沙直冲过堰、清水转弯进瓶口；
3. **宝瓶口"引清排浑" + 岁修**：瓶口前回流漩涡把靠近瓶口的底沙卷回堰口排出，
   过瓶口的只剩细颗粒悬沙，随灌溉水淤在田里反成肥料；残余淤积靠岁修"深淘滩"
   清除——"深淘滩、低作堰"就是这套机理的运维手册。

模型中每颗粒子带深度属性（表层清水/底层含沙），按上述机理概率路由；
开"环流剖面"开关可看横断面力原理插图。

## 与景区官方原理图的对照

数值与机理按都江堰景区"都江堰水利工程原理示意图"展板校准：

- **四六分水**：由"内江深窄 / 外江宽浅"的过水断面面积随水位自动算出——枯水位低
  时水全走内江深槽（约六成），洪水位高时外江宽浅断面面积增长更快（约四成）；
- **飞沙堰**：内江进流超过约 200 m³/s 时开始自行溢出；弯道环流 + 虎头岩壅堵 +
  宝瓶口/离堆壅水的联合作用，最多将进入内江沙石的约 70% 排出；全沙约 75% 由
  外江排走（展板口径）；
- **宝瓶口**：过水断面约 20.4m 宽 × 18.8m 高 × 36m 底长，"引清排浑"——瓶口前
  回流漩涡把靠近瓶口的底沙卷回堰口（模型中含沙粒子到瓶口会被回流送回飞沙堰）；
- **结构**：鱼嘴分水堤约 700m、飞沙堰 240m、金刚堤为内江右岸堤、离堆为宝瓶口
  旁的孤立石堆（模型均按示意尺度呈现）。

## 核心机理（粒子如何"懂"水利）

1. **弯道环流 → 二八分沙**：岷江在分水堤前转弯，弯道螺旋流使表层清水流向
   凹岸（内江一侧）、底层浑水甩向凸岸（外江一侧）。模型中每个粒子带一个
   深度属性 h，深层粒子在弯道向外漂移、在鱼嘴处以更高的概率进入外江——
   约 80% 的泥沙（"二八分沙"）随之排入外江。
2. **四六分水，随季节反转**：枯水期内江自然分额约六成（保证灌溉），
   来水越大份额越低，滑到四成。
3. **飞沙堰溢流排沙**：内江来水超过宝瓶口的通过能力时，超量部分在飞沙堰
   自动溢回外江；含沙粒子有额外的溢流概率——堰不但泄洪还"飞沙"，
   粒子会以一道水跃越过堰顶，肉眼可见。
4. **宝瓶口限流**：进口宽度骤缩，粒子在这里挤成一道急流，进流量被锁死在
   阈值内——无论上游来多大的水，灌区进流量几乎不变（"分四六、平潦旱"）。

右上角数据卡实时显示机理模型的流量分配（来水、宝瓶口进流、飞沙堰溢流、
外江下泄、泥沙外排比例），与粒子路由使用同一套概率，画面和数据互相印证。
**流量数值为示意量级**，用于展示机理，不是水文实测数据。

## 性能

2.4 万粒子（均衡）在桌面浏览器约 60 FPS；可选 1.2 万（流畅）或 4.5 万（精细）。
地形 200×200 网格一次性生成，河道、山体（岷山、玉垒山、离堆）、灌区渠系
均由河道中心线解析刻画。

## 文件

- `index.html` — 全部代码（地形生成、粒子仿真、渲染、交互）
- `start.sh` — 一键启动脚本
